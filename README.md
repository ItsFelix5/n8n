# What is this?
[n8n](https://n8n.io) is a low code online workflow building service, hc-n8n is a hack club community fork of it hosted for free!
This fork features wayy better slack bot support, easter eggs :3c, sign in with Hack Club, some custom hack club nodes and more!
Try it out at https://n8n.hackclub.community :D

# Features
* Custom branding
* Unlocked more features
* Disabled telemetry
* Added log in with hackclub
* Remove "built with n8n" attribution option on chat messages
* Easter eggs :D
* Custom featured nodes
* Improved slack integration for full app/workflow like capabilities
* Added a unique event url for all triggers of the same app (vanilla n8n only supports ONE workflow per bot)
* Improved the trigger event matcher and made it include all events
* Removed selecting users from list since that is a free immediate rate limit
* activation links (wip)
* Did some basic config hardening
* Prevented infinite loops from happening (again)
